# Test plots — exposición breve

## Español

Bien. Ahora, si miramos las gráficas de test.

Cada punto es un individuo evaluado en las 20 instancias de test. La línea negra es la media de cada indicador.

No vemos un comportamiento suave: es un poco caótico. Hay mucha variación entre individuos y entre generaciones.

Aun así, la búsqueda generó un operador que es bastante competitivo para MOEAD. Es decir, a pesar del ruido, el resultado final es bueno para ese algoritmo.

## English

Good. Now, if we look at the test plots.

Each point is one individual evaluated on the 20 test instances. The black line is the mean of each indicator.

We do not see smooth behavior: it is a bit chaotic. There is a lot of variation between individuals and between generations.

Even so, the search produced an operator that is quite competitive for MOEAD. So, despite the noise, the final result is good for that algorithm.
